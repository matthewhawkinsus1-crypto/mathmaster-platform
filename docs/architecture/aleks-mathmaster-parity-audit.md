# ALEKS / MathMaster Algebra II parity audit

## Verified rich-review capabilities

| Capability | MathMaster route | Verified scope |
| --- | --- | --- |
| Step-by-step inverse derivation | `inverseCompositionLab` / `deriveInverse` | Nonconstant linear functions; swap, balanced steps, undo, partial scoring |
| Function graph construction | `graphing2` | Algebra I and Algebra II catalog availability |
| Semantic transformation plotting | `transformationsLab` / `plotTransform` | Authored source points, parameters, bounds, and snap step preserved |
| Function operations | `functionOperationsLab` | Sum, difference, product, quotient, original-denominator exclusions, optional composition, partial scoring |

The function-operations certification is intentionally limited to function families accepted by its schema. Quotient restrictions are derived for linear and quadratic polynomial denominators; higher-degree denominator work requires authored exclusions and otherwise fails closed.

Curated review fidelity is also part of parity: MathMaster does not replace exam-looking teacher questions merely because they carry CCMR metadata. Audited-bank replacement and the approximately 15% Practice target require explicit enrichment intent. This audit does not claim broader nonlinear inverse derivation or arbitrary polynomial root solving.
